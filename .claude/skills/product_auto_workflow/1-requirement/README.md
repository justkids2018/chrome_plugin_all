# 需求优化器（Requirement Optimizer）

把模糊的想法转化为清晰的需求文档。

## 功能说明

这个模块帮助你：
- ✅ 通过3个关键问题快速明确需求
- ✅ 自动生成结构化需求文档
- ✅ 确保需求文档符合 doc/tel 规范

## 使用方法

### 1. 启动需求澄清

在 Claude Code CLI 中：

```
使用 requirement-optimizer 帮我澄清需求：[描述你的想法]

例如：
使用 requirement-optimizer 帮我澄清需求：给任务列表加优先级功能
```

### 2. 自动工作流程

```
[步骤 1] 识别需求类型
  → 检测关键词（优先级、搜索、标签、导出等）
  → 加载对应的提问模板

[步骤 2] 提出关键问题（最多3个）
  → 数据结构层面的问题
  → UI/UX 层面的问题
  → 功能范围的问题

[步骤 3] 生成需求文档
  → 使用 templates/feature-requirement.md 模板
  → 填充你的回答
  → 自动符合 tel 规范的"任务概览"和"上下文与假设"部分

[步骤 4] 保存到 examples/
  → 下次遇到类似需求可以参考
```

## 目录说明

### templates/
空白的需求文档模板，每次新需求时复制使用。

- `feature-requirement.md` - 功能需求模板
- `bug-report.md` - Bug 报告模板
- `refactor-plan.md` - 重构计划模板

### prompts/
针对不同需求类型的提问模板。

- `priority-feature.md` - 优先级功能（3个核心问题）
- `search-feature.md` - 搜索功能（3个核心问题）
- `tag-feature.md` - 标签功能（3个核心问题）
- `export-feature.md` - 导出功能（3个核心问题）

### examples/
已完成的真实需求案例，可以参考学习。

命名格式：`[功能名]-[日期].md`

## 示例

### 输入
```
我想给任务列表加个优先级功能
```

### AI 自动执行
```
✓ 识别到：优先级功能
✓ 加载：prompts/priority-feature.md

📝 需求澄清（3个关键问题）：

1. 【数据结构】优先级分几个等级？
   建议：3级（高/中/低）

2. 【UI设计】优先级如何展示？
   选项：颜色、图标、标签

3. 【功能范围】需要哪些功能？
   □ 排序
   □ 筛选
   □ 快速切换
```

### 用户回答
```
3个等级，用颜色（红/黄/灰），需要排序功能
```

### 输出
```
✅ 已生成需求文档：
   1-requirement/examples/priority-2026-01-07.md

📋 需求概要：
- 功能：任务优先级管理
- 等级：3级（高/中/低）
- UI：颜色标识（#FF3B30/#FFCC00/#8E8E93）
- 功能：优先级排序

✅ 需求明确度：85%

下一步：进入架构设计阶段 → 2-architecture
```

## 提示词开发指南

### 如何添加新的提问模板

当遇到新的功能类型时，可以在 `prompts/` 中创建新的提问模板：

```markdown
# [功能名]-feature.md

## 核心问题（最多3个）

### 问题 1：[数据结构层面]
问题内容...
建议答案...

### 问题 2：[UI/UX 层面]
问题内容...
选项...

### 问题 3：[功能范围]
问题内容...
checklist...

## 常见陷阱
⚠️ 注意事项...

## 参考案例
[链接到 examples/ 中的案例]
```
