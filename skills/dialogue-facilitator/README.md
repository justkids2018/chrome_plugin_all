# 💬 对话式需求澄清助手

通过智能对话帮助你理清开发需求，分析现有代码，生成清晰的开发方案。

## 功能特性

### 1. 智能对话引擎
- 自动识别需求中的**模块**（任务/历史/日程/番茄钟）
- 自动识别**操作类型**（添加/删除/修改/优化/排序/筛选）
- 自动识别**功能特性**（优先级/标签/搜索/导出/通知）

### 2. 智能提问系统
- 根据需求自动生成针对性问题（最多3个）
- 帮助明确数据结构、UI设计、功能细节
- 实时跟踪待确认问题和已确认要点

### 3. 代码分析
- 自动识别相关代码文件
- 检测技术栈
- 提供代码上下文

### 4. 需求明确度跟踪
- 实时显示需求明确度（0-100%）
- 视觉化进度条
- 达到80%自动启用文档生成

### 5. 自动生成
- 生成结构化需求文档
- 生成开发计划
- 支持导出和复用

## 使用方法

### 快速开始

1. **打开 Skill**
   - 在浏览器中打开 `index.html`
   - 或将整个 `dialogue-facilitator` 目录作为 Chrome 扩展加载

2. **描述你的需求**
   ```
   例如：我想在任务列表加个优先级功能
   ```

3. **回答 AI 的问题**
   - AI 会自动提出 2-3 个关键问题
   - 例如："优先级分几个等级？"
   - 你可以简单回答，不需要很详细

4. **查看分析结果**
   - **当前需求** tab：查看需求概述、待确认问题、已确认要点
   - **代码分析** tab：查看相关代码文件和技术栈
   - **输出文档** tab：生成需求文档和开发计划

### 对话示例

**场景：添加任务优先级功能**

```
User: 我想给任务列表加个优先级

AI: 好的，我理解了。你想在任务管理模块添加优先级功能。
    为了更好地实现这个功能，我需要了解几个细节：

    1. 优先级分几个等级？（建议：高/中/低 三级）
    2. UI上如何展示优先级？（标签、颜色、图标）
    3. 是否需要优先级排序和筛选功能？

User: 三个等级就好，用颜色区分，红色高优先级，黄色中等，灰色低优先级。
      要能按优先级排序。

AI: 明白了！我已经分析了相关代码，现在需求已经80%明确了。
    你可以点击"生成文档"按钮查看完整的需求文档和开发计划。
```

## 核心算法

### 需求信息提取

```javascript
// 检测模块
'任务|todo|待办' → 'task'
'历史|统计|分析' → 'history'
'日程|schedule' → 'schedule'

// 检测操作
'添加|增加|新增' → 'add'
'修改|更新|改成' → 'update'
'优化|改进' → 'optimize'

// 检测功能
'优先级|priority' → 'priority'
'标签|tag' → 'tag'
'搜索|search' → 'search'
```

### 智能提问策略

根据不同功能类型生成针对性问题：

- **优先级功能** → 问等级数量、UI展示、排序筛选
- **标签功能** → 问预设还是自定义、单个还是多个、UI展示
- **搜索功能** → 问搜索范围、是否需要高级搜索
- **通知功能** → 问触发时机、通知方式

### 明确度计算

```javascript
clarity = 0
if (module detected)    clarity += 30%
if (action detected)    clarity += 30%
if (feature detected)   clarity += 20%
if (no pending questions) clarity += 20%
```

## 数据持久化

- 使用 `localStorage` 保存对话历史
- 仅保存当天的对话（第二天自动清空）
- 支持刷新页面后恢复对话

```javascript
// 数据结构

  conversation: [...],      // 对话历史

```

## 最佳实践

### 1. 描述需求时
- ✅ 使用自然语言，不需要太正式
- ✅ 先说大概的想法，细节可以在对话中补充
- ✅ 一次说一个需求，避免混在一起
- ❌ 不需要提供技术细节（AI会自动分析）

### 2. 回答问题时
- ✅ 简单直接地回答即可
- ✅ 不确定的可以说"不确定"或"都可以"
- ✅ 可以反问 AI 获得建议
- ❌ 不需要写很长的解释

### 3. 使用建议
- 💡 对话3-5轮后，明确度通常能达到80%
- 💡 可以随时点击"清空对话"重新开始
- 💡 生成的文档可以作为与 AI 对话的输入
- 💡 开发计划可以作为任务拆分的参考
