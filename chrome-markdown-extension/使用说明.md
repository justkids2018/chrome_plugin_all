## Chrome Markdown 转换器 - 使用说明

### 快速开始 (3步上手)

#### 第一步：安装插件
1. 打开 Chrome/Edge 浏览器
2. 访问 `chrome://extensions/`
3. 启用右上角"开发者模式"
4. 点击"加载已解压的扩展程序"
5. 选择 `chrome-markdown-extension` 文件夹
6. 完成！插件图标会出现在工具栏

#### 第二步：转换网页
1. 打开任意网页 (如新闻、博客、文档)
2. 点击工具栏上的插件图标
3. 点击蓝色按钮 "Convert to Markdown"
4. 等待片刻，下方显示转换结果

#### 第三步：保存结果
- **复制**: 点击 "Copy to Clipboard" → 粘贴到笔记软件
- **下载**: 点击 "Download as .md" → 保存为 Markdown 文件
- **预览**: 直接在弹出窗口中查看和选择文本

### 功能选项详解

#### 1. 转换选项
- **Include page title**: 在开头添加页面标题 (推荐开启)
- **Include page URL**: 添加原文链接，方便回溯 (推荐开启)
- **Include metadata**: 添加作者、描述等完整信息
- **Filter ads and navigation**: 自动移除广告和导航栏 (清理杂乱内容)

#### 2. 内容选择器 (高级)
- **留空**: 自动识别主要内容区域
- **输入选择器**: 精确指定要转换的区域
- **常用示例**:
  - `article` → 转换整个文章区域
  - `.post-content` → 转换类名为 post-content 的元素
  - `#main` → 转换 ID 为 main 的元素
  - `.markdown-body` → GitHub 风格的文档内容

### 使用场景示例

#### 场景1：保存技术文档
1. 访问 MDN、GitHub 文档等
2. 点击插件图标
3. 开启"内容选择器"，输入 `.markdown-body`
4. 点击转换 → 复制 → 粘贴到你的笔记

#### 场景2：保存新闻文章
1. 打开新闻网站文章页
2. 点击插件图标
3. 开启"Filter ads and navigation"
4. 点击转换 → 下载为 .md 文件

#### 场景3：保存博客内容
1. 打开博客文章
2. 点击插件图标
3. 保持默认设置
4. 转换后复制到 Obsidian/Notion 等工具

### 常见问题

#### Q: 转换后的内容不完整？
**A**: 尝试:
1. 刷新页面后重试
2. 使用"内容选择器"指定具体区域
3. 关闭"Filter ads"选项再试

#### Q: 格式错乱或有乱码？
**A**: 尝试:
1. 只开启"Include title"和"Include URL"
2. 关闭其他选项
3. 手动清理特殊字符

#### Q: 某些网站无法使用？
**A**:
- 检查是否在支持的网站 (大多数标准网页)
- 部分动态网站需要特定选择器
- 可尝试查看页面源代码找主要内容区域

#### Q: 如何自定义样式？
**A**: 编辑 `src/content.js` 中的 `addCustomRules()` 函数

### 快捷键

- **Alt + 点击图标**: 快速转换 (需配置)
- **Ctrl+Shift+K**: 打开插件 (需配置)
- **转换后**: Ctrl+A 全选，Ctrl+C 复制

### 支持的内容类型

✅ **完美支持**
- 博客文章
- 新闻内容
- 技术文档
- GitHub README
- Stack Overflow 回答
- 维基百科文章

⚠️ **部分支持**
- 动态加载内容 (需等待加载)
- JavaScript 渲染页面
- 登录后内容

❌ **不支持**
- PDF 文件
- 视频/音频内容
- 图片中的文字
- Flash 内容
