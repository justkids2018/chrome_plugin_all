# Chrome Markdown 转换器 - 功能说明

## 概述
Chrome Markdown 转换器是一款功能强大的浏览器插件，能够将网页内容转换为 Markdown 格式，方便用户保存、编辑和分享网络内容。

## 功能列表

### 1. 一键转换功能 ⚡
- **位置**: 插件弹出窗口主按钮
- **功能**: 将当前网页内容转换为 Markdown 格式
- **操作**: 点击 "Convert to Markdown" 按钮
- **结果**: 自动生成 Markdown 内容并显示在文本框中

### 2. 智能内容识别 🔍
- **自动检测**: 智能识别网页主内容区域
- **支持选择器**: 
  - `article` - HTML5 文章标签
  - `main` - 主内容区域
  - `.content`, `.main-content` - 常见内容类名
  - `#content`, `#main-content` - 常见内容ID
  - `.markdown-body`, `.readme` - 代码仓库内容
- **后备方案**: 自动回退到 `document.body`

### 3. 转换选项定制 ⚙️

#### 3.1 内容包含选项
- **页面标题**: 包含网页标题到 Markdown
- **页面URL**: 包含原始网页链接
- **元数据**: 包含作者、描述等完整元数据
- **广告过滤**: 自动移除广告和导航元素

#### 3.2 自定义内容选择器
- **输入框**: CSS 选择器输入
- **功能**: 精确指定要转换的内容区域
- **示例**: `article`, `.post-content`, `#main`
- **错误处理**: 无效选择器自动回退

### 4. 多格式导出 📤

#### 4.1 复制到剪贴板
- **位置**: 弹出窗口 "Copy to Clipboard" 按钮
- **功能**: 将 Markdown 内容复制到系统剪贴板
- **快捷键**: 支持 Ctrl+C (Windows) / Cmd+C (Mac)
- **提示**: 显示成功复制状态消息

#### 4.2 下载为文件
- **位置**: 弹出窗口 "Download as .md" 按钮
- **文件命名**: `web-content-YYYY-MM-DD.md`
- **文件类型**: 标准 Markdown 文件 (.md)
- **内容**: UTF-8 编码的纯文本

#### 4.3 实时预览
- **位置**: 插件弹出窗口文本框
- **功能**: 显示转换后的 Markdown 内容
- **编辑**: 只读模式，便于复制选择
- **滚动**: 长内容支持滚动查看

### 5. 高级清理功能 🧹

#### 5.1 元素过滤
- **移除元素**: Script, Style, Noscript, Iframe 等
- **隐藏内容**: 自动移除 `display:none` 元素
- **空白节点**: 清理不可见元素

#### 5.2 广告识别
- **类名匹配**: 自动识别包含 `ad-`, `advert`, `banner` 等类名
- **ID匹配**: 识别广告相关的ID名称
- **角色匹配**: 识别导航、菜单等角色
- **移除内容**: Social, Share, Comment, Related 等区域

#### 5.3 格式优化
- **空白清理**: 移除多余空行（三个以上换行转为两个）
- **首尾清理**: 移除开头结尾的多余换行
- **代码处理**: 正确处理 `<pre>` 和 `<code>` 标签

### 6. 元数据提取 📋

#### 6.1 自动提取
- **页面标题**: `document.title`
- **页面URL**: `window.location.href`
- **当前时间**: ISO 8601 格式时间戳

#### 6.2 Meta 标签解析
- **描述**: `meta[name="description"]`
- **作者**: `meta[name="author"]`
- **发布时间**: `meta[property="article:published_time"]`

#### 6.3 输出格式
- **完整格式**: YAML Front Matter (包含所有元数据)
- **简洁格式**: 仅标题和链接
- **无元数据**: 纯内容模式

### 7. Markdown 格式支持 📝

#### 7.1 基础格式
- **标题**: H1-H6 转换为 `#` 到 `######`
- **段落**: `<p>` 标签转换为标准文本段落
- **换行**: `<br>` 转换为双空格+换行
- **水平线**: `<hr>` 转换为 `---`

#### 7.2 文本样式
- **粗体**: `<strong>`, `<b>` 转换为 `**bold**`
- **斜体**: `<em>`, `<i>` 转换为 `_italic_`
- **删除线**: `<s>`, `<strike>` 转换为 `~~strikethrough~~`
- **代码**: `<code>` 转换为 `` `code` ``

#### 7.3 链接和图片
- **链接**: `<a href="url">text</a>` 转换为 `[text](url)`
- **图片**: `<img src="url" alt="text">` 转换为 `![[text]](url)`
- **标题属性**: 支持链接的 title 属性

#### 7.4 列表和引用
- **无序列表**: `<ul>` 和 `<li>` 转换为 `- item`
- **有序列表**: `<ol>` 和 `<li>` 转换为 `1. item`
- **嵌套列表**: 自动处理缩进（两个空格）
- **引用**: `<blockquote>` 转换为 `> quote`

#### 7.5 代码块
- **行内代码**: `<code>` 内嵌在段落中
- **代码块**: `<pre><code>` 转换为围栏代码块
- **语言识别**: 支持 class="language-xxx" 语法高亮
- **转义**: 正确处理代码中的特殊字符

### 8. 用户界面功能 🎨

#### 8.1 弹出窗口设计
- **现代风格**: 清新简洁的用户界面
- **响应式**: 适应不同屏幕尺寸
- **分组布局**: 选项分组显示，便于理解

#### 8.2 交互元素
- **复选框**: 清晰的选项开关
- **输入框**: CSS 选择器输入区域
- **按钮**: 主要操作按钮和次要按钮
- **状态提示**: 成功/错误状态反馈

#### 8.3 视觉反馈
- **悬停效果**: 按钮悬停状态
- **点击反馈**: 按钮点击动画
- **状态颜色**: 成功（绿色）/错误（红色）状态
- **自动消失**: 提示消息3秒后自动隐藏

### 9. 数据持久化 💾

#### 9.1 选项保存
- **存储位置**: Chrome storage sync API
- **保存内容**: 用户选择的转换选项
- **自动保存**: 选项更改时自动保存
- **加载时机**: 弹出窗口打开时自动加载

#### 9.2 保存数据
- **包含标题**: boolean (默认: true)
- **包含URL**: boolean (默认: true)
- **包含元数据**: boolean (默认: true)
- **过滤广告**: boolean (默认: false)
- **内容选择器**: string (默认: 空字符串)

### 10. 错误处理机制 ⚠️

#### 10.1 用户输入错误
- **无效选择器**: 自动回退到智能识别
- **空内容**: 显示友好的错误消息
- **网络问题**: 处理页面加载失败

#### 10.2 转换错误
- **Turndown初始化失败**: 显示初始化错误
- **内容解析错误**: 提供详细的错误信息
- **API通信失败**: 处理消息传递错误

#### 10.3 浏览器兼容性
- **Clipboard API**: 提供降级方案
- **Storage API**: 处理存储限制
- **Manifest版本**: 兼容 Chrome 88+

## 使用方法

### 基本使用
1. 安装插件并固定到工具栏
2. 访问任意网页
3. 点击插件图标
4. 点击 "Convert to Markdown" 按钮
5. 复制或下载结果

### 高级使用
1. 打开插件设置选项
2. 选择要包含的内容类型
3. 输入自定义 CSS 选择器（可选）
4. 启用广告过滤（如需要）
5. 执行转换
6. 选择导出方式

## 技术特性

- **框架**: 原生 JavaScript (无依赖)
- **架构**: Chrome Extension Manifest V3
- **性能**: 快速转换，低资源消耗
- **安全**: 内容安全策略 (CSP) 兼容
- **可维护**: 模块化代码结构

## 注意事项

- 首次使用可能需要刷新页面
- 某些动态加载的内容可能需要等待加载完成
- 复杂的 JavaScript 页面可能需要特定选择器
- 大型页面转换可能需要较长时间
