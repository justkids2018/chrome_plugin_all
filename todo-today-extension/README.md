# 今日任务管理器 - Todo Today

一个简洁高效的 Chrome 扩展，帮助你管理今日待办事项，支持进度可视化、定时提醒和任务统计。

## ✨ 功能特性

### 🎯 核心功能
- **任务管理**: 添加、完成、删除今日待办事项
- **时间管理**: 为每个任务设置截止时间
- **进度可视化**: 实时进度条显示完成百分比
- **任务统计**: 总任务/已完成/待完成数量统计

### ⏰ 提醒功能
- **每小时提醒**: 自动提醒当前任务进度
- **任务到期提醒**: 提前15分钟提醒即将到期的任务
- **桌面通知**: 浏览器通知推送
- **图标徽章**: 工具栏图标显示剩余任务数

### 📊 数据可视化
- **动态进度条**: 带动画效果的进度显示
- **实时更新**: 任务状态变化即时反映
- **过期标记**: 逾期任务红色高亮显示
- **完成统计**: 详细的数据统计分析

## 🚀 安装使用

### 安装方法
1. 下载本扩展文件夹
2. 打开 Chrome/Edge 浏览器，访问 `chrome://extensions/`
3. 启用右上角"开发者模式"
4. 点击"加载已解压的扩展程序"
5. 选择 `todo-today-extension` 文件夹
6. 完成！插件图标会出现在工具栏

### 快速开始
1. 点击工具栏上的 📋 图标打开扩展
2. 在输入框中输入任务内容
3. 选择任务截止时间（可选）
4. 点击"添加"按钮或按回车键
5. 任务会自动显示在列表中
6. 勾选复选框标记任务完成

## 📋 使用说明

### 添加任务
- **任务内容**: 在文本框中输入任务描述（最多100字符）
- **截止时间**: 点击时间选择器设置任务到期时间
- **快捷键**: 输入完成后按回车键快速添加

### 任务管理
- **完成任务**: 点击任务前的复选框标记完成
- **删除任务**: 点击任务右侧的"删除"按钮
- **清除已完成**: 点击底部的"清除已完成任务"按钮

### 进度跟踪
- **进度条**: 实时显示完成百分比，带动画效果
- **统计数据**: 显示总任务数、已完成数和待完成数
- **图标徽章**: 工具栏图标显示剩余任务数量

### 提醒设置
- **每小时提醒**: 勾选"开启每小时提醒"启用
- **到期提醒**: 设置时间的任务会提前15分钟提醒
- **通知点击**: 点击通知可直接打开扩展查看任务

### 过期处理
- **逾期标记**: 超过设定时间的任务显示为红色
- **自动清理**: 每天自动清理已完成的过期任务
- **数据保留**: 未完成的旧任务会保留到当天

## 🛠️ 技术实现

### 核心技术
- **Manifest V3**: Chrome 扩展最新标准
- **Storage API**: 数据持久化存储
- **Alarms API**: 定时提醒功能
- **Notifications API**: 桌面通知
- **纯前端**: HTML5 + CSS3 + ES6+

### 数据结构
```javascript
{
  id: "unique_id",
  text: "任务内容",
  time: "18:30",        // 可选
  completed: false,
  createdAt: "2024-01-01T00:00:00.000Z",
  completedAt: null
}
```

### 主要功能模块
1. **TaskManager**: 任务管理核心类
2. **DOM Renderer**: 界面渲染和更新
3. **Progress Calculator**: 进度计算和显示
4. **Reminder Scheduler**: 提醒调度器
5. **Data Persistence**: 数据持久化层
